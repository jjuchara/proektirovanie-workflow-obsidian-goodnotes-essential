# Project verification

Read `.projectAgents/context/project-intelligence/quality-contract.md`. Verify the current deliverable using the criteria and project commands defined there. For document work, check provenance, completeness, contradictions, structure, and requested format. For software work, run the declared checks. Report fresh evidence and residual risk.
