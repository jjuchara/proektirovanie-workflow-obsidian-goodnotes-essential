# Project overview

Проектирует и проверяет управляемый пользователем workflow экспорта рукописных материалов и аннотированных PDF из Goodnotes Essential в Obsidian и PARA на MacBook, iPad и iPhone. Obsidian vault синхронизируется через GitHub и ObSync; проект включает реализацию Obsidian-плагина для безопасного review экспортов.

## Classification

- Name: Проектирование workflow Obsidian + Goodnotes (Essential)
- Kind: `mixed`
- Domain: Personal knowledge management, Goodnotes Essential, Obsidian, GitHub, ObSync, Apple Shortcuts and Obsidian plugin development
- Working language: Russian
- Expected artifacts: Russian canonical project documentation, Apple Shortcuts, Goodnotes templates, Markdown sidecars, Obsidian Dataview and Tasks configuration, manual verification evidence, Obsidian plugin source code, tests and release artifacts when explicitly requested
- Capability packs: coding, research, documentation, source-verification
